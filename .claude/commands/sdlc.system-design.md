# sdlc.sys-design
 ## Software Development Life Cycle: System Design

In this stage, developers and architects turn the requirements blueprint into a technical architecture.

Core Activities
High-Level Design (HLD): Defining the overall system architecture, database structure, and major modules.
Low-Level Design (LLD): Detailed design of individual components, class diagrams, and API endpoints.
UI/UX Design: Creating wireframes, mockups, and user interface workflows.
Technology Selection: Choosing specific programming languages, frameworks, and hosting platforms.

Primary Output
The main deliverable is the Design Document Specification (DDS), which developers use as their direct instruction manual for coding.
