<!--
  Shared git-attribution rule.
  @-included by every /codely.*, /sdlc.*, and /trainer.* command that creates a
  commit or PR.
-->

Every commit message and PR title/body this command writes is free of AI attribution — no "Co-Authored-By" line naming an AI or assistant, no "Generated with <tool>" note, no emoji or phrase implying an AI wrote it, no other AI-attribution signature. This holds even if a global or default tool configuration would otherwise add one — this instruction wins for every commit and PR this command creates.
